# Migration scope

Includes SAM3 attack implementations, dataset adapters, local SAM3 source/configs/assets, evaluation tools, analysis scripts and dataset split lists.

Excludes private runtime files, media, checkpoints, perturbations, predictions, historical defense trials and work/ucd_repro (a separate reproduction workstream).

Historical reports retain their original scope. No fresh training or evaluation was run during migration. Machine-specific paths require configuration.

SAM3 source derives from https://github.com/facebookresearch/sam3 . DarkSAM and AdvCLIP adaptations are identified in source. Preserve upstream attribution and applicable licenses; the local SAM3 snapshot has no license file.
